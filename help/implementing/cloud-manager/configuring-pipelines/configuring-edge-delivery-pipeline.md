# Add an Edge Delivery pipeline {#configure-edge-delivery-pipeline}

Learn how to configure production pipelines to build and deploy your code to production environments. A production pipeline deploys code first to the stage environment. On approval, it deploys the same code to the production environment.

A user must have the **[Deployment Manager](/help/onboarding/cloud-manager-introduction.md#role-based-permissions)** role to configure an Edge Delivery pipeline.

>[!NOTE]
>
>The features described in this article are only available through the early adopter program. For more details and to sign up as an early adopter, see [Bring Your Own Git](/help/implementing/cloud-manager/release-notes/current.md#gitlab-bitbucket).
