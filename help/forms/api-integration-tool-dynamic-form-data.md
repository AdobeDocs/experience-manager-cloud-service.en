# API Integration Tool for Dynamic Form Data {#api-integration-tool-dynamic-form-data}

The API Integration Tool lets form authors build smart forms that fetch and fill in data from external REST APIs, based on what a user does in the form. This no-code tool turns a plain, static form into a form that responds to the user in real time.

## Key capabilities

* **Visual configuration interface**: Set up API integrations using a simple, point-and-click interface. No custom code needed.
* **Real-time data population**: Fill in form fields automatically based on user input. For example, auto-fill a city and state when the user enters a zip code.
* **Flexible API support**: Connect to any public REST API. The tool supports GET and POST methods, authentication, and JSON or XML responses.
* **Rule-based triggers**: Choose when an API call runs, using the built-in rule engine. For example, run a call when a field changes or when a form event happens.
* **Smart data mapping**: Decide how data from an API response maps to specific form fields, using Adobe's JSON parsing tools.
* **Better user experience**: Cut down manual data entry, reduce errors, and make forms feel more responsive.

## Use cases

* Auto-completing an address when a user enters a zip or postal code
* Populating a dropdown list with options fetched from an external system
* Validating a value in real time against an external database
* Building a form that adapts its fields based on what the user has already entered

## Ready to start?

To set up your first API integration, add the API Integration Tool component to your Adaptive Form and configure the connection details for your external REST API from the component's properties panel.
