# Configure Forms Experience Builder UI options

>[!NOTE]
>
> The Forms Experience Builder is available under an early access program. Before you begin, please ensure you have requested and been granted access.

The Forms Experience Builder provides various UI configuration options to customize the interface according to your workflow preferences and organizational needs.

## Interface customization options

### Delete Conversation

Remove a specific conversation thread from your Forms Experience Builder history:

**When to use:**

- Remove conversations with sensitive or confidential information
- Clean up old or irrelevant conversation threads
- Maintain privacy and data security

**How to delete:**

1. Navigate to the conversation history panel
2. Locate the conversation you want to delete
3. Click the delete icon next to the conversation
4. Confirm the deletion in the popup dialog

**Important notes:**

- Deleted conversations cannot be recovered
- This action only removes the conversation from your local history
- Form data and configurations created in the conversation remain intact

### Start new Conversation

Begin a fresh conversation thread in Forms Experience Builder:

**When to use:**

- Start working on a new form project
- Switch between different form creation tasks
- Organize your work into separate conversation threads
- Clear context for a new form creation session

**How to start:**

1. Click the "New Conversation" button in the interface
2. Or use the keyboard shortcut (Ctrl+N or Cmd+N)
3. A new conversation thread will be created
4. Begin describing your new form requirements

**Benefits:**

- Keeps different form projects organized
- Provides a clean slate for new form creation
- Maintains conversation history for each project
- Improves AI context and response accuracy

### Clear Chat

Clear the current conversation while keeping the conversation thread:

**When to use:**

- Remove all messages from the current conversation
- Start fresh within the same conversation thread
- Clean up a cluttered conversation without losing the thread
- Reset the conversation context while maintaining the thread

**How to clear:**

1. Open the conversation you want to clear
2. Click the "Clear Chat" option in the conversation menu
3. Confirm the action in the popup dialog
4. The conversation thread remains but all messages are removed

**Difference from delete:**

- **Clear Chat**: Removes messages but keeps the conversation thread
- **Delete Conversation**: Removes the entire conversation thread
- **Start New Conversation**: Creates a completely new conversation thread
