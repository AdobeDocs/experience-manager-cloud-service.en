# Site Migration Skill {#site-migration}

Use the Site Migration skill to onboard websites into Edge Delivery Services with the help of AI and Adobe Forward Deployed Engineers. The skill automates content and style migration and prepares an author-ready EDS implementation that you can evolve in code and through AEM authoring.

## Overview {#overview}

The Site Migration skill transforms an existing site or design into an Edge Delivery Services project:

* **Sources**: an existing website (any CMS, including AEM 6.5, Managed Services, or Cloud Service), a design system, or design mocks (for example, Figma).
* **Outputs**: a production-ready Edge Delivery Services repository with blocks and styles applied.
* **Targets**: all Edge Delivery Services platforms and authoring methods are supported as targets.
* **Operating model**: delivered by Adobe Forward Deployed Engineers who operate the agent and guide the migration to ensure quality and governance.

## What the skill does {#capabilities}

The Site Migration skill performs the following high-level tasks:

1. **Content migration**  
   Convert pages and assets into Edge Delivery content structured using default content and blocks aligned to your selected block library.

2. **Style application**  
   Create styles for Edge Delivery in one of the following ways:
   * **As-is style migration** from the current site.
   * **Redesign** using provided mocks (for example, Figma).
   * **Reuse existing block designs** from an existing Edge Delivery implementation.

Typical deliverables include:

* EDS repository (blocks, styles, configuration)
* Migrated content and assets
* Authoring configuration (Document Authoring or Universal Editor)
* Edge Delivery Services environments (Preview and Live) with the migrated site deployed

The outcome is a production-ready website optimized for performance (Core Web Vitals/Lighthouse), accessibility, and responsive layouts across breakpoints, fully editable via Document Authoring or the Universal Editor.

## What’s not included (current limitations) {#limitations}

The Site Migration skill focuses on content and style. The following use cases require additional implementation effort on top of the Site Migration skill:

* Custom integrations (for example, commerce, CRM, search connectors).
* Dynamic content or rendering (for example, asynchronously loaded content, single-page applications, or bespoke JavaScript frameworks).
* Net-new feature development unrelated to the migrated experience.

If you require these capabilities, Adobe Consulting Services or your implementation partner can extend the delivered Edge Delivery project.

## Engagement model {#engagement}

The Site Migration skill is currently available through an engagement operated by Adobe Forward Deployed Engineers. Each project begins with a scoping exercise based on source complexity, design goals, content scale, and governance requirements.

To explore a migration:

* Contact your Adobe representative or account team to initiate scoping and scheduling.
* Adobe will confirm eligibility, estimate the engagement, and propose a migration plan.
