# Micro-Frontend Content Fragment Selector {#micro-frontend-content-fragment-selector}

The Micro-Frontend Content Fragment Selector provides a user interface that easily integrates with the AEM repository. The interface allows you to browse or search the content fragments available in the repository, and use them in your application authoring experience.

The Micro-Frontend user interface is made available in your application experience using the Content Fragment Selector package. Any updates to the package are automatically imported and the latest deployed Asset Selector loads automatically within your application.
