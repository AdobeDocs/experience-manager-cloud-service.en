# Content Fragments with Adobe Journey Optimizer {#content-fragments-with-journey-optimizer}

Using the Content Fragment Selector you can now browse any Content Fragment created in Adobe Experience Manager (AEM) as a Cloud Service directly from within Adobe Journey Optimizer (AJO).
