# Experience Modernization Agent 2026.10.16 Release Notes {#release-notes}

These are the release notes for the 16 October 2026 release of the Experience Modernization Agent (EMA) and its console.

>[!TIP]
>
>For the latest release notes for the Experience Modernization Agent, please see [this page.](/help/release-notes/modernization-agent/current.md)

>[!TIP]
>
>For the current release notes for Adobe Experience Manager as a Cloud Service, please see [this page.](/help/release-notes/release-notes-cloud/release-notes-current.md)

## What's New {#what-is-new}

* **Auto mode for sites that require sign-in:** Auto mode can migrate sites that require sign-in, using a user name and password, a bearer token, or a custom header. The credentials are sent only to that site and are not stored. See [Trial your brand's content.](/help/ai-in-aem/agents/brand-experience/modernization/getting-started.md#brand-trial)

## Other Improvements {#other-improvements}

* Page migrations produce better results.
* Cataloging sites with more than 1,000 pages completes reliably, and the chat tells you when page analysis is interrupted and resumed.
* Very tall pages keep their blocks when page templates are detected.
* Cataloging pages from an uploaded URL list shows its completion summary for the correct site.
