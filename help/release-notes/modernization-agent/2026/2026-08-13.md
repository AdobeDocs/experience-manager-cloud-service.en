# Experience Modernization Agent 2026.08.13 Release Notes {#release-notes}

These are the release notes for the 13 August 2026 release of the Experience Modernization Agent (EMA) and its console.

>[!TIP]
>
>For the latest release notes for the Experience Modernization Agent, please see [this page.](/help/release-notes/modernization-agent/current.md)

>[!TIP]
>
>For the current release notes for Adobe Experience Manager as a Cloud Service, please see [this page.](/help/release-notes/release-notes-cloud/release-notes-current.md)

## What's New {#what-is-new}

* **Custom block library from chat:** Ask the agent to generate a block library for your custom blocks, including sample content and library configuration, for Document Authoring or AEM authoring. See [Block deliverables.](/help/ai-in-aem/agents/brand-experience/modernization/block-development.md#block-deliverables)

## Other Improvements {#other-improvements}

* You no longer need to reconnect GitHub manually when your access token expires.
* Large branch switches and slow checkouts no longer freeze the workspace.
* Content and images are correct for sites whose content location differs from the site name.
* Migrations complete noticeably faster.
