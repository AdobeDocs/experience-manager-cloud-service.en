# Experience Modernization Agent 2026.05.25 Release Notes {#release-notes}

These are the release notes for the 25 May 2026 release of the Experience Modernization Agent (EMA) and its console.

>For the latest release notes for the Experience Modernization Agent, please see [this page.](/help/release-notes/modernization-agent/current.md)

## What's New {#what-is-new}

* **Dynamic Media and Scene7 images:** Images served by Adobe Dynamic Media or Scene7 are migrated as responsive images, with their parameters preserved.
* **Header and footer migration:** Dedicated skills migrate site headers and footers and check their appearance before completion.
