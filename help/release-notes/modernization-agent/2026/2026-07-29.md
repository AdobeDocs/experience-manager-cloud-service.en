# Experience Modernization Agent 2026.07.29 Release Notes {#release-notes}

These are the release notes for the 29 July 2026 release of the Experience Modernization Agent (EMA) and its console.

>[!TIP]
>
>For the latest release notes for the Experience Modernization Agent, please see [this page.](/help/release-notes/modernization-agent/current.md)

>[!TIP]
>
>For the current release notes for Adobe Experience Manager as a Cloud Service, please see [this page.](/help/release-notes/release-notes-cloud/release-notes-current.md)

## What's New {#what-is-new}

* **Modern web best practices:** The agent applies Google's Modern Web Guidance when it writes or edits CSS and client-side JavaScript.
* **Media copied during transfer:** Transferring content to Document Authoring also copies the images and media that the pages reference. See [Make it yours.](/help/ai-in-aem/agents/brand-experience/modernization/getting-started.md#make-it-yours)

## Other Improvements {#other-improvements}

* Previews stay stable under heavy use.
* Preview styling renders correctly.
* Preview links open correctly for catalog-based projects.
* The **Changes** tab no longer shows internal tool output.
* For AEM authoring projects, content-mapping problems are shown in the JCR XML view.
