# Universal Editor 2026.04.02 Release Notes {#release-notes}

These are the release notes for the 2 April 2026 release of the Universal Editor.

>[!TIP]
>
>If you wish to test **upcoming** Universal Editor features before they are released, please see the [Universal Editor Preview Release Notes.](/help/release-notes/universal-editor/preview.md)

>[!TIP]
>
>For the current release notes for Adobe Experience Manager as a Cloud Service, please see [this page.](/help/release-notes/release-notes-cloud/release-notes-current.md)

## What's New {#what-is-new}

* [A configurable option](/help/implementing/universal-editor/configure-rte.md#special-characters) to [add special characters](/help/sites-cloud/authoring/universal-editor/authoring.md#formatting-options) has been added to the rich text editor (RTE) toolbar.

## Other Improvements {#other-improvements}

* Tag fields are no longer wrongly returned as multi-fields by the OpenAPI adapter.
